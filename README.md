# JustTrack

Android-приложение для управления телефоном жестами через фронтальную камеру. Использует MediaPipe Hand Landmarker (21 точка руки) и работает полностью на устройстве: кадры никуда не передаются, разрешения `INTERNET` нет.

## Режимы и жесты

Сначала система активируется: **открытая ладонь 1.5 с** (двойная вибрация). Через **10 с** без жестов она сама деактивируется. Режим переключается удержанием **✌️ 1.5 с**.

| Жест | 🎵 Медиа | 🎮 Управление |
|------|----------|---------------|
| Тап (коснуться кончиками большого и указательного) | Play / Pause | Клик (в точке курсора, если он поставлен, иначе в центре) |
| Двойной тап | Следующий трек | Назад |
| Тройной тап (срабатывает сразу на третьем) | Предыдущий трек | Домой |
| Зажать и вести вверх/вниз | Громкость | Плавная прокрутка |
| Зажать и резко вести влево/вправо | — | Свайп влево/вправо |
| ☝️ Указательный вверх (остальные согнуты) | — | Курсор-кружок на кончике пальца |
| ☝️ → коснуться большим пальцем | — | Клик там, где был курсор (сразу, без ожидания) |
| 👍 держать 0.8 с | Список приложений | Список приложений |
| 👎 держать 0.8 с | Предыдущее приложение | Предыдущее приложение |

Одноразовые позы (✌️, 👍, 👎) срабатывают один раз за удержание: чтобы повторить, руку нужно опустить или сменить позу.

Касание считается относительно размера ладони: по умолчанию кончики большого и указательного должны сойтись ближе 20% длины ладони. Поэтому оно не зависит от того, насколько рука далеко от камеры. Порог меняется в настройках («Чувствительность захвата»).

## Как пользоваться

1. Установи APK и открой приложение.
2. Нажми **«Запустить JustTrack»** и разреши камеру. Уведомления не обязательны: без них сервис работает, просто уведомление со Stop не видно (остановить можно из приложения).
3. Для режима «Управление» приложение покажет, чего не хватает:
   - **Специальные возможности** — нужны для нажатий, свайпов и системных кнопок. Перед переходом в настройки показывается объяснение, что именно используется.
   - **Поверх других окон** — чтобы курсор и подсказки были видны в других приложениях.
4. Покажи открытую ладонь и держи 1.5 с.
5. Можно свернуть приложение: камера и распознавание продолжают работать в foreground-сервисе, подсказки рисуются поверх других приложений.

На экране блокировки нажатия и системные действия не выполняются.

### Важно для Samsung

**Настройки → Приложения → JustTrack → Батарея → Без ограничений**, иначе One UI может остановить фоновый сервис.

## Архитектура

```
app/src/main/java/com/justtrack/app/
├── GestureService.kt          — единственный владелец камеры, MediaPipe и FSM; публикует TrackingStatus
├── MainActivity.kt            — UI: привязывается к сервису, показывает превью, статус и чек-лист настройки
├── HandTrackingEngine.kt      — кадр → MediaPipe → PinchVolumeGesture → FrameResult
├── PinchVolumeGesture.kt      — state machine жестов (чистый Kotlin, покрыт тестами)
├── OneEuroFilter.kt           — сглаживание курсора без лага при быстром движении
├── ScreenMapper.kt            — единственное преобразование курсора в пиксели экрана (и для отрисовки, и для тапа)
├── ScreenController.kt        — действия режима «Управление» через Accessibility
├── SwipeAccessibilityService.kt — жесты/глобальные действия + история переднего приложения для 👎
├── ForegroundAppTracker.kt    — текущее и предыдущее приложение (только в памяти)
├── VolumeController.kt        — громкость и медиа-клавиши
├── HandOverlayView.kt         — отрисовка руки, прогресса, курсора и обратной связи
├── TrackingStatus.kt          — STOPPED / STARTING / RUNNING / ERROR(причина)
├── BootReceiver.kt            — напоминание после перезагрузки (камеру из boot запускать нельзя)
├── PrefsKeys.kt, SettingsActivity.kt
```

Камера, распознавание и состояние жестов живут только в `GestureService`. Activity при показе подключает к нему свой `PreviewView`, а при уходе в фон отключает. Поэтому активация, режим и курсор не сбрасываются при сворачивании, и камеру не делят два владельца. Статус RUNNING выставляется только когда реально приходят результаты распознавания; если кадров нет 4 с, показывается ошибка.

### State machine жестов

```
INACTIVE → (ладонь) → ACTIVATING → (1.5 с) → IDLE
IDLE → (поза подтверждена ≥3 кадра и ≥100 мс, рука неподвижна):
   pinch → PINCHED → (отпустил < 300 мс) → TAP_WAITING → (450 мс) → действие тапа
                   → (держит > 300 мс)   → VOLUME_MODE (громкость / скролл / свайп)
   ✌️ → MODE_SWITCHING (1.5 с) → смена режима
   👍/👎 → THUMB_GESTURE (0.8 с) → список / предыдущее приложение
   ☝️ (Управление) → CURSOR_MODE (курсор = кончик указательного)
        → касание большим → клик в точке курсора 120 мс назад
        → опустил палец → курсор сохранён на 5 с, следующее касание кликает туда
Потеря руки: удержания (активация, ✌️, 👍/👎, незавершённый pinch) отменяются;
             перетаскивание и курсор переживают пропуск до 250 мс.
Любое активное состояние → (10 с без жестов) → INACTIVE
```

## Стек

- Kotlin, compileSdk/targetSdk **36**, minSdk 26
- CameraX 1.3.4 (Preview + ImageAnalysis, 4:3)
- MediaPipe Tasks Vision **0.10.35** (16 KB page-size совместимые native-библиотеки)
- Material Components 1.11.0, AndroidX Preference 1.2.1
- AGP 8.12.3, Gradle 8.13, JDK 17

## Сборка

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n com.justtrack.app/.MainActivity
```

## Тесты

```bash
./gradlew testDebugUnitTest   # 145 unit-тестов
./gradlew lintDebug           # 0 ошибок
```

- `PinchVolumeGestureTest` — активация, тапы и серии тапов, громкость, скролл, свайпы, ✌️/👍/👎 с повторным взводом, курсор указательным пальцем, потеря руки, гистерезис pinch, устойчивость к повороту руки
- `VolumeControllerTest` — громкость, медиа-клавиши, вибрация, dispatch
- `GestureActionTest` — набор действий
- `OneEuroFilterTest` — сглаживание курсора
- `ForegroundAppTrackerTest` — история приложений для 👎
- `PrefsKeysTest` — формулы порогов

Для профилирования конвейера кадра в коде есть trace-секции `JT.bitmap`, `JT.detectSubmit`, `JT.gesture` (Perfetto / Android Studio Profiler).
